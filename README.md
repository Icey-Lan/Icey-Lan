## 🆕 最近在做：Paper Deep Analysis Skill

把论文深读从一次性对话，变成可追溯、可校验、可被人和 Agent 共同使用的研究工作流。

📄 [**paper-deep-analysis-skill**](https://github.com/Icey-Lan/paper-deep-analysis-skill) — 输入本地 PDF、公开 PDF URL 或 arXiv ID，生成面向人类阅读的离线 HTML 报告，以及面向 Agent 后续检索与比较的 schema-validated JSONL 数据。语义分析由 Agent 完成，Python 工具负责来源准备、解析、渲染、校验与 provenance。

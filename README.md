## 最近追的三个问题

### 读过的论文，怎么不消失在 PDF 和聊天记录里？

[paper-deep-analysis-skill](https://github.com/Icey-Lan/paper-deep-analysis-skill) 把 PDF 或 arXiv 论文整理成离线深读报告和结构化数据。

### 每分析一个岗位，为什么都要重新介绍自己？

[JobBuff](https://github.com/Icey-Lan/JobBuff) 把 JD 分析、简历修改和面试准备放进同一个任务过程。

### 十几个职位标签页，能不能变成一张真正可管理的表？

[job-hunter-web](https://github.com/Icey-Lan/job-hunter-web) 在本地采集职位信息，并跟踪投递状态。

## 🆕 New: Paper Deep Analysis Skill

Turning paper reading from a one-off chat into a traceable, validated research workflow that both people and Agents can use.

📄 [**paper-deep-analysis-skill**](https://github.com/Icey-Lan/paper-deep-analysis-skill) — Takes a local PDF, public PDF URL, or arXiv ID and produces an offline HTML report for human readers plus schema-validated JSONL for downstream Agent retrieval and comparison. The Agent performs semantic analysis; deterministic Python tools handle source preparation, extraction, rendering, validation, and provenance.
